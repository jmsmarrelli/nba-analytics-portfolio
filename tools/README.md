# Tools

- `fetch_snapshot.py`: download pinned inputs and verify their hashes.
- `export_for_r.py`: rebuild the six compact R extracts from processed tables.
- `publish.py`: render the finished Markdown articles to standalone HTML.
- `notebooks.py`: create and execute the lightweight result-review notebooks.

Run from the repository root. `make all` documents the complete order. Native R was used for this release; no browser-based R runtime is required.
